STUNTMASTER PC - START HERE
==========================

This archive is portable. Extract the whole folder somewhere writable, then:

  1. Run stuntmaster-launcher.exe.
  2. Browse to the folder containing your legally obtained Jackie Chan
     Stuntmaster BIN/CUE dump.
  3. Choose the display settings and press Play.

Do not copy game files into this archive. Only the USA / NTSC-U SLUS-00684
single-track MODE2/2352 release is supported. Required BIN SHA-256:

  0DFC8FCB055E2EBF22380F5FF7568706376588FDCF8C4086DCFCA67DC8295E14

Settings are written to stuntmaster.ini beside the launcher. Memory-card and
quick-save files are written under the saves folder. Keep that folder when
upgrading if you want to retain your saves.

Default keyboard controls:

  Move       W / A / S / D       Punch      J
  Interact   K                     Kick       L
  Jump       Space                 Start      Escape
  Quick save F5                    Quick load F9
  Fullscreen Alt+Enter

Edit input.ini for the complete keyboard/gamepad bindings. See README.md for
status, advanced controls, source, licenses, and troubleshooting context.
